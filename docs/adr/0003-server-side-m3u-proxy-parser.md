# Parse M3U playlists server-side via a proxy endpoint

Open TV is being generalized from a Brazil-filtered iptv-org player into a generic M3U player that accepts any playlist URL supplied by the user. Parsing the M3U purely client-side would let us delete all server logic, but arbitrary user-supplied playlist URLs frequently lack CORS headers, so a browser `fetch()` would fail opaquely. To keep the "accepts any playlist" promise honest and to allow server-side validation of the response, we keep a single server endpoint that fetches + parses the M3U and returns normalized channel JSON. The Astro live content collection and the iptv-org-specific enrichment (BR filter, blocklist, feed `format`, resolved category names) are deleted; fetching happens only when a playlist URL is added/saved or when the user clicks Refresh in Settings — never automatically on page load.
