# Models

There are certain LLM models that are better than others in specific tasks.

As I'm using `opencode-go` for developing this project, here is a list of OSS
models I use, and what they are good for

## Kimi-k2

Good for:

- Visual Thinking, UI/UX work, creative tasks
- Brainstorming

Not good for:

- logical tasks
- following multiple orders
- long context

Token Limit for "smart" thinking: 10%

## MiniMax-M3

Good for:

- calculations, logical steps
- good to following orders

Not good for:

- visual tasks
- long context

Token Limit for "smart" thinking: 10%

## Deepseek-v4

Good for:

- Not so smart, but hard-working!
- Can reasoning about context for longer

Not good for:

- visual tasks

Token Limit for "smart" thinking: 5%
