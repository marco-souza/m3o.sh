## Have you ever written a game by hand?

I did! In fact, this was one of the first things I did once I felt I had the
bare minimum skills to write a game - tic-tac-toe, it was. 15 years later, during
the AI doom age, I've been feeling burned out and tired of how things are progressing.

### Odin Programming language

I try to learn at least one new programming language a year - this is Odin's year!

Odin fits a place in my heart reserved for statically typed, and compiled
languages - C, Go, Rust, and now Odin is earning its place. It comes with all you
need to build a game since your first tutorial.

Features I like most:

- great ergonomics (types, structs, core concepts)
- a great standard library
- vendor support (I'm using raylib <3)
- compiles to WASM

Features I'm missing:

- a better formatter - one that integrates with neovim (btw)
- an http module - client and server, like `go`

### Earning my joy back

In this project I **won't use AI code** - but I might use it for learning and
asking questions. I wanna write the code by hand, compile it, and go through
all the learning pains that are so important to avoid becoming a meat-proxy - I
hope AI doesn't steal my learning.
